# Architecture Summary

> Dự án dùng mô hình **Laravel monolith** (Blade + Vite) thay vì tách Next.js/Node.js riêng, để dễ deploy trên hosting PHP thông thường (ServBay, shared hosting, VPS) chỉ bằng `git pull`.

## Tech stack

| Layer | Công nghệ | Vai trò |
|---|---|---|
| App | Laravel (PHP 8.3+) | Toàn bộ: routing, business logic, REST API, RBAC, CMS Admin, và render giao diện (Blade) |
| Frontend rendering | Blade + Vite + Tailwind CSS v4 | Giao diện render phía server, design token kiểu shadcn/ui, không cần chạy tiến trình Node riêng khi hosting |
| Rich text editor | TinyMCE (tự host qua npm, không cần API key) | Soạn nội dung bài viết — heading, danh sách, ảnh, bảng, code, blockquote |
| HTML sanitization | `mews/purifier` (HTMLPurifier) | Lọc nội dung TinyMCE trước khi lưu DB — chặn XSS server-side, không dựa vào trình duyệt |
| Database | MySQL 8.4 (InnoDB) | Lưu trữ quan hệ, migrations, table prefix `mxd_` |
| Cache/session/queue | File / sync (mặc định) | `SESSION_DRIVER=file`, `CACHE_STORE=file`, `QUEUE_CONNECTION=sync` — **không phụ thuộc Redis**, để cài được trên hosting phổ thông chỉ có PHP + MySQL. Redis vẫn cấu hình sang được qua `.env` nếu server có, nhưng là tuỳ chọn tăng tốc chứ không phải yêu cầu. *(Dòng này trước đây ghi Redis là bắt buộc — sai và đã lỗi thời so với cấu hình thật; để nguyên sẽ khiến người đọc tưởng CMS không chạy được trên shared hosting.)* |
| Realtime (khi cần) | Laravel Reverb hoặc Pusher | Chưa triển khai — dự kiến thay cho Node.js/Socket.io khi cần, vì nằm trong hệ sinh thái Laravel |
| Web server | Nginx hoặc Apache + PHP-FPM | Trỏ document root vào `public/`, không cần reverse-proxy sang tiến trình Node nào. Host không đổi được document root thì dùng `.htaccess` + `index.php` ở thư mục gốc (xem README). Môi trường phát triển của tác giả dùng ServBay, nhưng sản phẩm không phụ thuộc vào nó. |

## Cài đặt lần đầu (Installation Wizard)

Trình cài đặt web 4 bước tại `/install` (đã hoàn thành, đã khoá bằng `install.lock` trên site hiện tại):

1. **System Pre-flight Check** — kiểm tra PHP >= 8.2, extension bắt buộc, quyền ghi `storage/`, `bootstrap/cache`.
2. **Database Configuration** — nhập host/port/database/username/password/table prefix, nút "Test Connection", tự ghi `.env` + chạy `migrate`.
3. **Site & Admin Initialization** — site title, tagline, ngôn ngữ, múi giờ, tạo tài khoản Super Admin đầu tiên.
4. **Lock & Completion** — ghi `storage/app/install.lock`; middleware `EnsureAppIsInstalled` chặn `/install` sau khi khoá.

Code: `app/Http/Controllers/Install/InstallController.php`, `app/Http/Middleware/EnsureAppIsInstalled.php`, `app/Services/EnvironmentWriter.php`.

## Core Engine đã xây

- **Auth**: `/login`, `/logout`, session-based (Laravel guard `web`) — `app/Http/Controllers/Auth/AuthenticatedSessionController.php`.
- **Admin shell**: `/admin` — sidebar + topbar responsive, dark/light tự động theo `prefers-color-scheme` — `resources/views/layouts/admin.blade.php`. **Menu sidebar nhóm cha/con + thu gọn (2026-08-25)**: mục "Nội dung" cũ (1 link duy nhất, gộp hết loại nội dung sau tab nội bộ) tách thành **1 mục điều hướng riêng cho từng loại nội dung đã đăng ký** — vòng lặp `@foreach (get_post_types() as ...)` tính **động** từ `PostTypeRegistry`/`TaxonomyRegistry` (tự nhận loại nội dung mới nếu sau này đăng ký thêm CPT, không hardcode). Loại nào có taxonomy riêng (post→category+post_tag, product→product_category) hiện dạng **nhóm cha/con xổ xuống** (`<x-nav-group>`, tự mở khi trang hiện tại thuộc nhóm đó); loại không có taxonomy (page/service/project) hiện **link phẳng** — tránh xổ xuống rỗng vô nghĩa. Component mới: `<x-nav-group>` (toggle cha + `<x-nav-subitem>` con, JS accordion trong `admin.js`, không lưu trạng thái đóng/mở vì đã tự mở đúng theo trang hiện tại mỗi lần tải). **Nút thu gọn sidebar** (`#sidebar-collapse-toggle`, chỉ hiện ở `lg:`) chuyển sidebar còn icon, ẩn hết label qua class `.sidebar-collapsed` (CSS thuần trong `app.css`, chỉ áp dụng `@media (min-width:1024px)` — không đụng hành vi mobile) — trạng thái lưu `localStorage`, áp dụng bằng script inline trong `<head>` trước khi trang vẽ (tránh flash sai trạng thái ở lần tải cứng; Turbo không đụng `<html>` nên state tự giữ nguyên qua các lần điều hướng Turbo).

Bài học: **accordion cha/con chỉ hợp cho quan hệ nội dung↔danh mục thật** (nơi ẩn bớt thật sự giảm rối); với việc gom nhóm thuần trực quan (không có quan hệ cha/con thật), nhãn nhóm tĩnh đúng hơn — hỏi lại đúng use case trước khi chọn pattern UI. `<x-nav-subitem>` được mở rộng thêm prop `:icon` (tuỳ chọn, dùng cho con của Bài viết/Sản phẩm nếu cần, hiện các mục Hệ thống không còn dùng nữa vì đã chuyển về `<x-nav-item>` phẳng).

**Bug Blade thật phát hiện khi thêm nhóm Hệ thống**: cú pháp rút gọn `@php($bien = ...)` (1 dòng) đặt CÙNG 1 file với cú pháp khối `@php ... @endphp` (nhiều dòng) phía sau nó khiến Blade compiler không đóng đúng thẻ `<?php ?>` cho dòng rút gọn — mọi thứ phía sau (kể cả `@if`/`{{ }}`/`@endcan`) bị bỏ qua không biên dịch, `php -l` trên file `.blade.php` gốc **không phát hiện được** (chỉ hiện lỗi khi biên dịch ra PHP thật, vd qua `php artisan view:cache` hoặc `Blade::compileString()` thủ công). Sửa bằng cách đổi TẤT CẢ về dạng khối `@php ... @endphp`, không trộn 2 kiểu cú pháp trong cùng 1 file. **Quy tắc cho dự án**: luôn dùng dạng khối `@php ... @endphp`, tránh dạng rút gọn `@php(...)` khi file đã có/sẽ có khối `@php` khác.

  - **Core Web Vitals — Real User Monitoring thật**: bảng `performance_metrics`, JS tự host `resources/js/rum.js` (thư viện `web-vitals` qua Vite, không CDN) đo LCP/INP/CLS/FCP/TTFB thật từ trình duyệt khách, gửi qua `navigator.sendBeacon('/rum', ...)` — route `POST /rum` (`PerformanceMetricController`) không CSRF (sendBeacon không gắn được header, xem `bootstrap/app.php`'s `validateCsrfTokens(except:)`), không yêu cầu đăng nhập, chỉ ghi số liệu tổng hợp (không gắn `visitor_id`). Sức khỏe Website tính **p75** mỗi metric trong 7 ngày qua, so ngưỡng chuẩn Google, hiện "Chưa đủ dữ liệu thật" nếu dưới 20 mẫu thay vì suy diễn.
  - **Sao lưu dữ liệu thật**: `App\Support\BackupService` — `mysqldump` (dò đường dẫn qua `.env MYSQLDUMP_PATH` hoặc các vị trí thường gặp) + nén `storage/app/public` (media) vào 1 file zip tại `storage/app/backups/`, giữ 7 bản gần nhất. Lệnh `php artisan backup:run`, lên lịch `dailyAt('02:00')` (`routes/console.php`, cần cron gọi `schedule:run` mỗi phút ở server thật). Nút "Sao lưu ngay" trên trang Sức khỏe gọi trực tiếp, đồng bộ — đã test thật: tạo file zip ~2.3MB chứa `database.sql` + toàn bộ media, xác nhận nội dung dump hợp lệ.
  - **Truy vấn CSDL chậm**: bảng `slow_queries`, ghi qua `DB::listen()` trong `AppServiceProvider` (chỉ khi có request web thật, bỏ qua console/migration) — chỉ lưu **câu SQL mẫu, không lưu giá trị tham số** (tránh lộ dữ liệu form/tìm kiếm của khách), có guard chống tự đệ quy nếu chính câu INSERT log bị chậm.
  - **Cache & Hiệu năng**: driver + kết nối cache, OPcache, config-cache khi production, Redis Cache Hit Ratio (chỉ hiện khi `CACHE_STORE=redis`, bỏ qua hoàn toàn nếu không — không giả số cho driver khác), tỉ lệ ảnh đã tối ưu WebP/AVIF trong Thư viện ảnh; nút "Xoá cache" gọi `Artisan::call('cache:clear')` thật.
  - **Bảo mật mở rộng**: `.env` không nằm trong `public/`, HTTP security headers (+ HSTS khi có HTTPS — `SecurityHeaders` middleware), **chứng chỉ SSL/TLS** (tự kiểm tra thật qua `stream_socket_client`/`openssl_x509_parse` vào cổng 443 của chính site, báo ngày hết hạn thật), thuộc tính cookie phiên (`Secure`/`HttpOnly`/`SameSite` đọc từ `config/session.php`), trạng thái rate-limit đăng nhập/liên hệ (dò qua `Route::gatherMiddleware()`), toàn vẹn tệp tải lên (`Storage::exists()` từng file Media, phát hiện file bị mất trên đĩa), số IP đang bị chặn.
  - **Hạ tầng**: Load Average (`sys_getloadavg()`), số kết nối CSDL đang mở/`max_connections` (`SHOW STATUS`/`SHOW VARIABLES` thật, MySQL), dung lượng đĩa trống, PHP/extension.
  - **SEO kỹ thuật**: `robots.txt`/`sitemap.xml` tự kiểm tra reachable + hợp lệ (self-probe), thẻ Canonical (xác nhận tĩnh — đã có sẵn trên mọi trang), **độ phủ Schema.org/JSON-LD theo từng loại nội dung** (self-probe 1 bài mới nhất mỗi post_type) — phát hiện `show-product.blade.php`/`show-project.blade.php` thiếu hoàn toàn JSON-LD (chỉ `show.blade.php` có) và đã bổ sung (`Product`/`CreativeWork` schema tương ứng).
  - **Chất lượng nội dung**: độ phủ thẻ Alt ảnh (cột mới `media.alt_text`, sửa trực tiếp tại Thư viện ảnh — ô text tự lưu khi rời khỏi ô, `onblur="this.form.requestSubmit()"`), toàn vẹn tệp, cấu trúc thẻ H1 (self-probe 5 bài mới nhất, đếm `<h1` — đúng chuẩn phải đúng 1 thẻ/trang), **Content Decay thật** (`contentDecay()` — so lượt xem 30 ngày gần nhất với 30 ngày trước đó từ `page_views`, liệt kê bài giảm ≥40%, không phải điểm "mức độ hấp dẫn" bịa ra).
  - **Tích hợp & Theo dõi**: trình gửi email (+ nút "Gửi email thử nghiệm" gửi thật qua `Mail::send()`, không chỉ đọc config), phát hiện Tracking Pixel đã cấu hình (quét chuỗi `gtag(`/`fbq(`/`ttq.` trong nội dung `custom_head_scripts`/`custom_footer_scripts` đã lưu ở Cài đặt).
  - **Chặn IP (tường lửa tầng ứng dụng, không giả)**: bảng `blocked_ips`, middleware `app/Http/Middleware/BlockBannedIps.php` (**prepend** vào nhóm `web` — chạy sớm nhất, chặn cả public lẫn `/admin/*`, tự bỏ qua an toàn nếu chưa cài đặt/DB lỗi). Quản lý thêm/gỡ ngay trên trang Sức khỏe Website — đã test thật: tự chặn `127.0.0.1` → xác nhận 403, gỡ chặn → xác nhận 200 lại.
  - **Rate limiting thật**: `throttle:5,1` trên `POST /login`, `throttle:10,1` trên `POST /lien-he` (`routes/web.php`) — đã test qua 6 lần POST liên tục, lần thứ 6 nhận đúng 429.
  - **Lỗi & 404**: bảng `error_logs` (`type`: `error`|`not_found`). Ghi qua `bootstrap/app.php`'s `withExceptions()` — **404 phải dùng `$exceptions->render()`, không phải `reportable()`**, vì `NotFoundHttpException` nằm trong danh sách "không report" mặc định của Laravel nên `reportable()` không bao giờ được gọi cho nó (bug thật gặp phải, đã fix — xem ghi chú trong memory). Chỉ ghi lỗi ở trang public (`/admin/*` bị loại trừ). Trang Sức khỏe Website hiển thị lỗi gần đây + top 404 (7 ngày, gộp theo URL) để tìm liên kết hỏng.

**Lưu ý phạm vi**: không có mảng "Ecommerce" trong app — Sản phẩm là catalog affiliate (không giỏ hàng/doanh thu thật), không bịa số liệu doanh thu giả (đã xác nhận với người dùng khi tham khảo TailAdmin/shadcn để thiết kế lại các trang trên).

### Trang public — hoàn thiện toàn bộ (2026-09-07)

Trước đợt này chỉ có trang chủ được thiết kế lại; các trang còn lại vẫn là bản dựng nhanh ban đầu và **thiếu hẳn nhiều trang mà một website nội dung bắt buộc phải có**. Đợt này bổ sung đủ và đưa mọi trang về cùng một ngôn ngữ thị giác với trang chủ.

**Trang/route mới**

| Route | Tên | Vì sao cần |
|---|---|---|
| `/danh-muc/{slug}`, `/the/{slug}`, `/loai-san-pham/{slug}`, `/the-san-pham/{slug}` | `taxonomy.show` | Trước đây badge danh mục/thẻ hiển thị trên mọi trang chi tiết nhưng **không dẫn đi đâu cả** — ngõ cụt cho cả người đọc lẫn Google |
| `/tim-kiem` | `search` | Website không có tìm kiếm; nay tìm trên cả 5 loại nội dung, có chip lọc kèm số đếm thật |
| `/tac-gia/{slug}` | `author.show` | Tên tác giả in ra ở mọi bài nhưng không click được; trang tác giả làm rõ tác quyền (E-E-A-T) |
| `/feed.xml` | `feed` | RSS 2.0 — không có feed thì không ai theo dõi được blog |

**Template mới**: `taxonomy`, `search`, `author`, `show-service` (trước đây Dịch vụ dùng chung template bài viết), `public/feed`.

**Component dùng chung mới**: `<x-marketing.content-card>` (thay 6 bản sao chép thẻ nội dung ở blog/dịch vụ/dự án/sản phẩm/danh mục/tìm kiếm), `page-hero` (đầu trang, tự thành "sân khấu ảnh" khi có ảnh), `empty-state`, `related`, `author-box`, `post-nav`, `share`.

**Nâng cấp trang cũ**: blog (bài nổi bật + chip danh mục + thẻ nội dung), archive Dịch vụ/Dự án/Sản phẩm (chip taxonomy + lời dẫn riêng từng loại + CTA khép trang), Liên hệ (honeypot, ContactPage/ContactPoint schema, kênh liên hệ), chi tiết bài viết (thời gian đọc, thẻ có link, chia sẻ, hộp tác giả, bài trước/sau, bài liên quan), chi tiết Sản phẩm (cột thông tin dính, sản phẩm liên quan), chi tiết Dự án (dải thông tin khách hàng/thời điểm, dịch vụ liên quan), 4 trang lỗi.

**Bug thật tìm được khi kiểm thử**

1. **`@if` viết dính ngay sau chữ không được biên dịch** — `Mới nhất@if (...)` trong `default/index.blade.php`. Blade dò directive bằng regex có `\B` trước `@`: sau một ký tự chữ thì đó là word boundary nên `@if` bị bỏ qua, trong khi `@endif` (đứng sau dấu `)`) vẫn được biên dịch → view vỡ với *"syntax error, unexpected token endif"*. **Lỗi này bị theme con `minimal` che hoàn toàn** (nó ghi đè đúng file đó), chỉ lộ ra khi tạm bật `ACTIVE_THEME=default` để kiểm thử. Đã thêm bước quét toàn bộ Blade tìm directive dính liền chữ.
2. **Script hiệu ứng `.reveal` nằm trong `home.blade.php`** — mọi trang khác gắn class `.reveal` sẽ **ẩn vĩnh viễn** vì không có IntersectionObserver nào chạy. Đã chuyển script lên `layout.blade.php`.
3. **`.reveal-image` không bao giờ được kích hoạt** (xem mục trang chủ ở trên) — cùng một script, đã sửa luôn khi chuyển.
4. **Canonical bỏ mất `?page=`** — `url()->current()` bỏ query string, nên trang 2, 3… của mọi archive đều khai canonical trỏ về trang 1. Với Google nghĩa là "các trang này trùng nội dung trang 1" → toàn bộ bài từ trang 2 trở đi mất index. Đã sửa ở `layout.blade.php`.
5. **View phân trang mặc định của Laravel hard-code bảng màu Tailwind** (`bg-white`, `text-gray-500`) → dark mode ra chữ trắng trên nền trắng. Đã thay bằng `resources/views/vendor/pagination/mxd.blade.php` chỉ dùng token màu, đăng ký qua `Paginator::defaultView()` (ảnh hưởng cả admin — đã kiểm thử riêng 4 trạng thái: trang đầu, trang giữa, trang cuối, chỉ-1-trang).
6. **Chip lọc đang bật có tương phản chữ 2.41:1** — dùng `--primary` (#f97316) làm màu chữ trên nền tint của chính nó. **Đo thật**, dưới ngưỡng AA 4.5:1 cho cỡ chữ 13px. Đã đổi: nền + viền cam giữ vai trò tín hiệu, chữ dùng `--foreground` → 16.16:1.
7. **N+1 ở `Post::related()`** — thẻ nội dung gọi `primaryTerm()` và `getMeta()` cho từng mục liên quan; chưa nạp sẵn quan hệ thì mỗi thẻ tốn thêm 3 truy vấn. Đã `->with(['author','terms','meta'])`.

**Thêm vào Model/DB**
- `users.slug` (migration mới, nullable + unique, tự backfill) — URL trang tác giả. `User::booted()` tự sinh slug ở **mọi** đường tạo tài khoản (form admin, installer, seeder, tinker) chứ không chỉ ở controller.
- `Post::url()`, `readingTime()` (200 wpm trên text đã strip tag, tối thiểu 1 phút), `primaryTerm()`, `related()`, `adjacent()`; `priceAmount()` nhận tham số key để dùng lại cho `price_from` của Dịch vụ.
- `Term::url()` — trả **null** khi taxonomy chưa có route archive, template bắt buộc phải kiểm tra null (nếu không, một taxonomy do plugin đăng ký sẽ sinh link 404 chắc chắn).
- Custom field mới cho Dịch vụ: `price_from`, `duration` (form admin render custom field theo vòng lặp nên tự có mặt, không phải sửa view).

**SEO**
- Sitemap bổ sung 5 trang danh sách cố định + archive theo term (chỉ term có bài đã xuất bản).
- Schema mới: `CollectionPage` (archive + taxonomy), `Blog` (trang blog), `ProfilePage`+`Person` (tác giả), `ContactPage`+`ContactPoint` (liên hệ), `Service` có `offers` **chỉ khi** có `price_from` thật.
- `/tim-kiem` đặt `noindex, follow` — mỗi truy vấn sinh một URL mới, để index sẽ tạo vô số trang mỏng gần trùng.
- `<link rel="alternate" type="application/rss+xml">` ở layout.

**Chống spam form liên hệ**: honeypot (`website`) ẩn bằng cả CSS lẫn `aria-hidden`/`tabindex=-1`, không dùng `type="hidden"`. Bot bị chặn vẫn nhận đúng thông báo thành công để không dò ra cơ chế. **Đã test thật**: gửi 1 lượt người thật + 1 lượt có điền honeypot → chỉ bản ghi người thật vào DB.

**Kết quả kiểm thử** (26 URL, dữ liệu thử nghiệm 22 bài/10 term rồi dọn sạch): mọi trang 200/404 đúng; đúng 1 thẻ `<h1>` mỗi trang; không có cuộn ngang ở 1440px lẫn 375px; sticky header còn nguyên; tương phản dark mode ≥ 7.9:1 ở mọi chữ; feed.xml và sitemap.xml parse hợp lệ; 8–20 truy vấn DB mỗi trang.

**Lưu ý vận hành**: dữ liệu thử nghiệm đã xoá sạch (`zzt-*`). Trang chủ vẫn đang hiện `TE` ở chương "Đối tác đồng hành" — đó là `client_name` của bản ghi Dự án test cũ **của người dùng**, cần thay bằng dự án thật trước khi lên chính thức.

## Bảo mật

- Mật khẩu hash bằng Bcrypt (mặc định Laravel).
- 100% truy vấn DB qua Eloquent ORM / prepared statements.
- CSRF token tự động trên mọi form (Laravel mặc định).
